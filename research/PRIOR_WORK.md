# Prior work: SIH 26078 (MoES / NCMRWF)

AI-driven spatio-temporal tracking of extreme-weather anomalies in 3–10 day ensemble forecasts, plus amplitude-preserving downscaling from 12 km to 5 km over India (0–40N, 60–100E).

## Method note

- Sources were fetched on 2026-09-27. Each entry was checked against a primary page we actually fetched: an arXiv abstract or API record, Crossref DOI metadata or abstract, a Semantic Scholar record, a journal or publisher landing page, an official competition page, a Zenodo record, a GitHub repository page, or a raw README.
- Every link was then checked by script, with the results in research/LINKS_CHECK.csv.
- Each entry has exactly one URL, and it sits in the Link column. We prefer arXiv or doi.org links. Some doi.org links redirect to publisher pages (Wiley, Elsevier, AMS, IOP) that can return HTTP 403 to scripted clients even though the DOI is valid.
- Link check on 2026-09-27 (final status after redirects): 5 doi.org/Zenodo pages returned 403 to scripts. The 4 DOI entries now link to their Crossref metadata record (api.crossref.org/works/<DOI>, title verified to match). The Zenodo PrecipCorrDiff dataset entry was removed because both its HTML page and its API record returned 403 to the checker.
- "not reported" means the fetched source did not state the item. It does not mean the paper lacks it.
- Numbers in the SIH-repo group are copied from each repo's own README as self-reported by its authors. We did not re-run any of their code, and none of it has been copied into this project.

## Our differentiation

- Exact ground truth. Synthetic events (Holland-profile cyclones on real IBTrACS tracks, heat domes, cold waves) are merged onto real ERA5 backgrounds, so every pixel, 4D bounding box and centroid of every event is known exactly. Other repos score against one real storm, or on synthetic data without exact event masks.
- Conservation by construction. The 5 km truth is block-averaged conservatively to 12 km, so avgpool(5 km) equals 12 km exactly (following Harder et al.). The planned diffusion downscaler enforces the same constraint at its output instead of adding it as a soft loss or a stub.
- Realistic 20-member ensembles: spread grows with lead time, and there are deliberate miss members and false-alarm members. This lets us measure hit, miss and false-alarm behaviour of the tracker, which no SIH-26078 repo evaluates.
- Object-level scoring: a threshold + connected-components + Hungarian tracker scored with IoU against exact 4D labels and with centroid error in km across many events and leads, not a single case study.
- Transparent classical baselines (EFI following Lalaurette 2003, and z-score anomalies) that every learned model has to beat before we report it.
- Honest realism validation of the synthetic data: power spectra, p99 amplitudes, and the cyclone radial wind profile compared with Amphan, with ERA5's known TC-intensity low bias kept in mind.
- NEPS-G-compatible variable naming and member layout (23-member convention), so real NCMRWF NEPS-G fields can replace the synthetic ones without code changes.
- A clear roadmap: an icosahedral GNN tracker (GraphCast-style mesh) and a conservation-constrained CorrDiff-style diffusion downscaler, each benchmarked on the same exact-truth dataset against the baselines above.
